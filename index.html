它真的会花钱

这不是模拟器。每一轮都会向你填写的地址发送真实 HTTP 请求，并以服务商的 token 统计为准。API Key 不会离开浏览器，除了发送到你填写的 API 地址。

跨域（CORS）被拦截时，请改用服务商允许的域名、自己的后端代理，或仓库里的命令行版本。

项目宣言

我们不再假装 token 是抽象数字。每一个数字都来自一次真实请求、一次真实账单、一次对未来绩效制度的提前适应。严肃，但不一定有用。

01 / 连接

国产模型预设

内置 DeepSeek、Qwen、GLM、MiniMax、混元模型名预设，也接受任何 OpenAI-compatible 服务。

02 / 计量

100 万 → 10 亿

目标范围覆盖 100 万到 10 亿 tokens，页面会输出预期总量、预计请求次数和估算费用。

03 / 刹车

以 usage 为准

读取 prompt、completion 和 total tokens；达到目标自动停止，遇到错误会停止并写入日志。
